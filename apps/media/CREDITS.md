# Content credits and licences

Generated content is checked in under `data/json/`. Anything adapted from an
external source keeps that source's licence, and share-alike terms are
indebted here rather than left in a commit message.

## Reading comprehension — Belebele

`data/json/<lang>/assessments/<exam>/comprehension-*.json` are generated by
`scripts/generate-comprehension.ts` from the **Belebele** benchmark.

- Source: <https://huggingface.co/datasets/facebook/belebele> and
  <https://github.com/facebookresearch/belebele>
- Licence: **CC-BY-SA 4.0** (`LICENSE_CC-BY-SA4.0` in the repository)
- Passages originate from **FLORES-200** (<https://github.com/facebookresearch/flores>),
  itself CC-BY-SA 4.0, derived from Wikinews / Wikivoyage text.

**Share-alike obligation.** These passages are adapted (trimmed, re-banded by
length, re-wrapped in the exercise format), so the adapted content inherits
CC-BY-SA 4.0. Anyone redistributing these exercises must do so under the same
licence, and must keep the attribution. Every exercise carries a
`passageSource` line naming Belebele, the licence and the originating Wikivoyage
page, and the app surfaces it under the passage.

**Not used.** The same repository ships an assembled training set under
`LICENSE_CC-BY-NC4.0` — non-commercial. It is deliberately not read; the
generator pulls only the CC-BY-SA main dataset.

**Levelling caveat.** Belebele carries no CEFR, JLPT or HSK label. The three
banks per language are split by passage length alone, which is a proxy for
difficulty and not a proficiency judgement. Belebele is a benchmark built to be
hard, so the lower tiers are optimistic, and the levels below each exam's
lowest tier still have no comprehension material at all.
